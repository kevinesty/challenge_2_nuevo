# Challenge 2 — IRA y neumonía en menores de 5 años en el Perú

Sitio web académico, responsive e interactivo para presentar los indicadores de infecciones respiratorias agudas (IRA) y defunciones por neumonía de 2023 a 2025.

## Abrir el sitio
1. Descarga y descomprime el ZIP.
2. Abre `index.html` con Chrome, Edge o Firefox.
3. Para publicar el sitio, puedes subir estos archivos a GitHub y activar GitHub Pages desde **Settings → Pages**.

## Tecnologías
- **HTML5**: estructura y contenido semántico.
- **CSS3**: diseño visual, responsive y estilos de impresión.
- **JavaScript**: selector de indicadores, tabla dinámica y gráfico en canvas.
- **Java**: no es necesario para este sitio estático; Java y JavaScript son lenguajes distintos. Si el curso exige Java de forma explícita, se puede añadir un backend Java (por ejemplo, Spring Boot), pero para mostrar la web en GitHub Pages no hace falta.

## Indicadores utilizados
- Episodios de IRA: 2023 = 1,003,178; 2024 = 883,959; 2025 = 824,978.
- Defunciones por neumonía: 2023 = 113; 2024 = 82; 2025 = 51.

Los valores corresponden al material de referencia compartido para el trabajo y no se han verificado de manera independiente en este paquete. Las puntuaciones de la matriz de alternativas son ilustrativas, no datos oficiales ni mediciones de impacto.

## Archivos
- `index.html`: contenido y secciones de la página.
- `styles.css`: diseño, adaptación a móviles y modo impresión.
- `script.js`: datos, gráfica interactiva y tabla.
- `assets/`: carpeta preparada para imágenes adicionales.
- `challenge_ira_neumonia_peru.md`: resumen del análisis y límites.
